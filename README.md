# NordicBites – pagarikoja veebileht

Õppeaine **„Veebilehtede loomine edasijõudnutele”** raames valminud rühmatöö.

Projekti eesmärk on realiseerida teise tudengirühma koostatud Figma prototüübi põhjal toimiv ja mobiilisõbralik veebileht.

## Veebilehe funktsionaalsus

- Avaleht ja pagarikoja tutvustus
- Tootekataloog koos kategooriafiltrite ja otsinguga
- Ostukorv toodete lisamise ja koguste muutmise võimalusega
- Tellimuse vormistamine koos vormiväljade kontrolliga

## Kasutatud tehnoloogiad

- HTML5
- CSS3
- Bootstrap 5 ja Bootstrap Icons
- JavaScript
- GitHub Pages
